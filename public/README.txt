IMAGE / ASSET NOTES
===================

The portfolio currently uses remote Unsplash image URLs so the design works immediately.

Replace these URLs in src/App.jsx if you want your own images:
1. profileImage = your portrait
2. projects[].image = screenshots for your projects
3. travel image = your own travel/personal image

For a fully self-contained GitHub Pages deployment, put images in:
public/images/

Then use:
"/images/profile.jpg"
"/images/project-1.jpg"

RESUME
======
Put your PDF at:
public/resume.pdf

The Download Resume button will then work automatically.
